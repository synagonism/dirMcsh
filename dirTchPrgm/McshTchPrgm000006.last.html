overview of CrxToc

description::
× Mcsh-creation: {2026-09-01} {2010-10-23}

· table-of-contents-Crx is a Google Chrome-Extension which creates an expandable table-of-contents on ANY web-page with heading-elements. If the page has many headings like scientific-papers, law, spec, help, etc files, this extension makes reading much more EASIER.

installation of CrxToc

description::
× Mcsh-creation: {2026-10-04}
online-installation:
1) go to extension's Chrome-website, with chrome browser.
2) just press "ADD TO CHROME" button.

local-installation:
1) download the compressed files and uncompress them in a local directory.
2) go to: chrome://extentions
3) check "Developer mode"
4) press "Load unpacked extension..." and find the directory where you have uncopressed it.
