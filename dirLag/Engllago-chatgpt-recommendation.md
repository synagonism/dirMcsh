# A Systematic Inventory of Modern Standard English Verb Constructions

Reference verb: WRITE · Contemporary Standard English · Active and passive voice

I will reorganize your original 205 entries into a consistent grammatical system, correct errors, add missing constructions, and exclude forms that are theoretically grammatical but extremely unnatural in ordinary modern English.

The main principle is to separate verb-phrase constructions from sentence patterns. For example, writes, does not write, does he write?, and doesn't he write? should not all be counted as different morphological forms of write. They represent different combinations of inflection, auxiliary support, polarity, and question formation.

## 1. Classification and notation

Each construction can be classified along several dimensions.

| Dimension           | Categories                                                               |
| ------------------- | ------------------------------------------------------------------------ |
| Finiteness          | Finite, nonfinite                                                        |
| Tense               | Present, past; future reference through auxiliaries                      |
| Aspect              | Simple, progressive, perfect, perfect progressive                        |
| Voice               | Active, passive                                                          |
| Polarity            | Positive, negative                                                       |
| Clause type         | Declarative, interrogative, imperative                                   |
| Modality            | Can, could, may, might, must, shall, should, will, would, ought to, etc. |
| Agreement           | Person and number                                                        |
| Other constructions | Going to, used to, have to, had better, and others                       |

In the tables below, I use she for active examples and the letter for passive examples, so that the sentences are grammatically and semantically natural.

## 4. Modal auxiliary constructions

Modal auxiliaries are especially important because they allow many additional constructions beyond the traditional tense–aspect system.

### A. Basic modal constructions

| ID  | Construction | Example           |
| --- | ------------ | ----------------- |
| M01 | can write    | She can write.    |
| M02 | could write  | She could write.  |
| M03 | may write    | She may write.    |
| M04 | might write  | She might write.  |
| M05 | must write   | She must write.   |
| M06 | shall write  | I shall write.    |
| M07 | should write | She should write. |
| M08 | will write   | She will write.   |
| M09 | would write  | She would write.  |

Will write is also represented in the future-reference section. That overlap is intentional: the same construction can serve different grammatical functions.

### B. Modal + aspect and voice

These structures combine a modal with other auxiliaries.

| Code | Structure                           | Example                             |
| ---- | ----------------------------------- | ----------------------------------- |
| MB01 | Modal + base                        | She might write.                    |
| MB02 | Modal + be + -ing                   | She might be writing.               |
| MB03 | Modal + have + past participle      | She might have written.             |
| MB04 | Modal + have been + -ing            | She might have been writing.        |
| MB05 | Modal + be + past participle        | The letter might be written.        |
| MB06 | Modal + have been + past participle | The letter might have been written. |

These six patterns can be combined with many modals, but not all combinations are equally natural or have the same meaning.

Examples you omitted include:

- can be written
- could have written
- could have been written
- may be writing
- may have written
- might have been writing
- must have written
- must have been written
- should be writing
- should have been writing
- should have been written
- would have been written

The modal can normally expresses present or general possibility/ability; could have written expresses a different kind of possibility or unrealized ability. This illustrates why structures should be classified by both form and meaning.

### C. Modal negation and questions

For example, with should write:

| Type              | Example               |
| ----------------- | --------------------- |
| Affirmative       | She should write.     |
| Negative          | She should not write. |
| Question          | Should she write?     |
| Negative question | Shouldn't she write?  |

Also distinguish She shouldn't write from She doesn't have to write: the first generally advises against writing, while the second indicates no obligation.

## 7. Nonfinite verb constructions

These are essential parts of your inventory. They do not independently express person or finite tense.

### A. Infinitives

| Code | Construction         | Example                                  |
| ---- | -------------------- | ---------------------------------------- |

| I02  | to be writing        | She hopes to be writing.                 |
| I03  | to have written      | She claims to have written it.           |

The base form without to is a bare infinitive in constructions such as can write, let her write, and make her write.

## 8. Imperative and hortative constructions

Your original list has please write and let's write, but it needs a more systematic imperative section.

| Code | Construction    | Example                 |
| ---- | --------------- | ----------------------- |
| H01  | write           | Write the letter.       |
| H02  | do not write    | Don't write the letter. |
| H03  | do write        | Do write to me.         |
| H04  | please write    | Please write soon.      |
| H05  | let's write     | Let's write together.   |
| H06  | let's not write | Let's not write today.  |
| H07  | let me write    | Let me write it.        |
| H08  | let her write   | Let her write.          |

Note that please is not an auxiliary verb. It marks politeness, so please write is better classified as a pragmatic variant of an imperative.

The 80 templates exclude separate modal, semi-modal, nonfinite, conditional, imperative, and agreement variants. Several constructions also overlap across categories and should not be counted twice.

The additional sections provide a structured extension, but they are not yet a fully enumerated, deduplicated master list of every accepted auxiliary combination. For example, might not have been written and shouldn't have been writing are generated by the modal rules without needing entirely new grammatical categories.

My recommendation is to preserve your original 205 IDs as historical identifiers, create new normalized construction IDs, and maintain a mapping from each original entry to its corrected or excluded status.
